# Single-EXE NBA Demo (API + UI)

This folder contains patched sources to run UI and API from a single FastAPI/Uvicorn process.

## Run from source (dev)

```bash
python nba_api.py
```
Open: http://127.0.0.1:8000/

## Build executables (Windows)

Run:

```bat
build_all.bat
```

## Runtime layout (portable)

Place these next to `nba_server.exe`:
- `dataset.json` (generated by `generate_dataset.exe`)
- `nba_config.json` (auto-created on first run if missing)

Reload dataset after regeneration:

```bash
curl -X POST http://127.0.0.1:8000/dataset/reload
```
